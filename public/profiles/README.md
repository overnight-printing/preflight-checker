# Standard CMYK fallback

`SWOP2006_Coated3v2.icc` is the unmodified X-Rite profile provided by
Idealliance through the [ICC Profile Registry](https://registry.color.org/profile-registry/SWOP2006_Coated3v2).

SHA-256: `27dc90dbeb399b76c0f91a6b387fe30c38939f034d2500712f3c43094be15e3b`.

The registry permits use, embedding, exchange, and sharing without restriction.
Altering or selling the profile requires written permission from Idealliance.
The profile is included unchanged, retains its embedded copyright/license text,
and is not sold as a separate product. Copyright: X-Rite.

This is a standard coated-web profile (CGATS TR003, 300% total ink limit),
not a measurement of the user's press. The app prefers a single embedded CMYK
output profile or a profile explicitly supplied by the operator. It shows this
SWOP profile as the fallback when neither is available. It does not claim this
is Adobe's U.S. Web Coated (SWOP) v2 or an exact match to CGATS TR001.
